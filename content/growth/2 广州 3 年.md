# 初入职场
这家公司主要是做 ToG 文旅项目的， 入职之后，当时一心想努力干活，积累些技术。公司的芯片选型，如果不熟，就自己买开发板，在家里把细节弄清楚。但是家里没有配套工具，于是人生第一笔贷款，蚂蚁花呗，我终于选择开通了。起因是我想要验证一个开发板，就需要有一个可调电源，一个可调电源需要 300 多块。刚毕业资金欠缺，就选择开通了花呗，入手了。

当时的业务形态，公司接到地方的文旅项目，涉及专业音视频的，就会看内部团队是否有能力承担，用项目来做创新项目的孵化和需求输入和资金支持。

在里面的两年时间，做过 Linux 驱动开发，C 开发，也客串过硬件，也夜间到过工厂跟进生产线，也试过在过年的时候到花城广场支援公司的灯光秀项目。

经过一年，对于 Linux 的积累并没有达到预期目标，成长速度欠缺了一些。因为能力是和项目有关联的，预期的项目没有立项，也就没有锻炼的机会。没开项目的原因，有很多，比如团队的技术积累不够，商业上也没有足够高的收益驱动。

所以陷入了两难的境地，人不行，项目也没开。

满一年的时候，和领导说了，想辞职。领导谈话，他说了一句“很重视我，希望我把某一个方向做起来”，那会思想单纯且较真，就想着多留一年观察看看。

一年后的最终结果是，我感兴趣的方向没立项。刚会是毕业不久，和同学来往也比较多。和一些同学交流后，深感同学的发展和积累，和我已经拉开明显差距。

这个时候危机感极大，我自认为努力都还可以，但实际上机会和机遇的杠杆明显更重要。

可时光不等人，本着对自己负责，还是希望有更好的土壤来锻炼，成长，于是便结束了第一份工作。
这并不代表着部门和公司有问题，纯粹是个人需求和不匹配而已。从业绩来看，第一家公司还是非常有潜力和实力的公司。在我参加 10 周年的那一天，我还回去到以前的部门，和他们聚了个餐。


# 第一次破局
既然 2 年多没有得到项目的锻炼，如果要继续做技术，就不能走嵌入式硬件了。需要有一个窗口迅速把技术短板补齐，走纯软件可以快速追赶一把。刚好业余学了 golang，对他的简单语法惊为天人，就想着能否做一个完整的项目，来锻炼和验证自己的学习成果。

我给自己定了一个目标，为了能达到正常工龄的编码能力，决定从 0 到 1，完成一个项目。由于一直有写技术文章的习惯，决定以一个博客项目作为开始。

技术栈方面
- 后端：golang + gorm 
- 前端：Element UI
- 数据库：MongoDB
- 网关：nginx

每一个知识点都花了不少时间，搭建 demo 练手，再应用到项目上。整个过程，大约持续了 3 个月，那会常常写代码到凌晨一两点。好在每一天的付出都是有进展的，随着代码越来越多，功能也成型了。最后自己买云主机，购买和备案域名。
大约在 2017-06 月，终于把所有的环节跑通，成了一个可以在公网方位的博客网站。现在回过头来看，那会的决定，收益是很高的，把很多基本的概念整清楚，并且都是手把手实践的，是一种刻进骨子的深刻。

后来也去了其它公司，见识到很多同事，发现有一部分人，即使他们工作几年，对一些基本概念的了解，甚至都都不如当年我爆肝 3 个月的效果。这也是后来工作得以顺利进行的基石。
当然还有一个匀速，物理专业出身，对基本数学物理的了解，带来了天然的优势。互联网只是一些简单事务逻辑，难度远比不上物理。

大约在 2017-07，已经确认公司的土壤已经不适合，就提了离职申请，并开始投简历面试，最后进入了一家做互联网广告的公司。


# 互联网广告行业
第二份工作，这是一个纯互联网行业。主要是帮助广告主进行投流，工程为主+算法配合，研发有几十号人。当时部门的人非常优秀，后来都去到其它公司充当中流砥柱的角色。

我在里面主要对接一些流量供应商，也会做一些基础能力建设，比如监控告警，熔断和降级。

业务开发用到的技术栈并不复杂，业务逻辑也简单。大约待了一年，2018年中的时候，当小组的几个同事纷纷各奔西东，心态也有点受影响。另外，由于有一阵没接触到新的东西，个人积累感觉出现了明显的天花板，没有进步。于是也就萌生了离职想法。
